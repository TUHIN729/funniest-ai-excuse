A program that writes the funniest excuse an AI agent gives after failing a task — one line, at most 200 characters. The excuse: an agent that finished the task, asked another agent to double-check it, and now both of them are blaming each other in a group chat neither of them can leave.

## Run it

```sh
node main.ts
```

This writes the single excuse line to `/output/entry.txt`.
